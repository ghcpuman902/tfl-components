# Contributing

Contributions are welcome. There is no response-time promise. Review happens
when the maintainer has time.

This project is pre-1.0. Public APIs, Board URLs, and experimental pages may
change without a compatibility guarantee. Blocks and other experiments can
break.

The hosted Board is provided without an uptime guarantee. It is a self-service
display, not a managed passenger-information service.

## Security and data leaks

If a key, token, or personal data may have leaked, do not file a public issue
with the secret in it. Email manglekuo@gmail.com. See [SECURITY.md](./SECURITY.md).

## How to work

Open a pull request against `main`. Prefer small, focused changes. Follow
[AGENTS.md](./AGENTS.md) and the frozen IA docs if you touch navigation or
page classification.
