## Introduction

**tfl-components** is the visual layer of a TfL developer environment. Together with [`tfl-ts`](https://www.npmjs.com/package/tfl-ts) (data) and this site, the goal is to discover London transport information, retrieve it cleanly, inspect normalised shapes, and render useful interfaces.

You copy component source with the shadcn CLI — not a locked npm UI package.

### Flow

```text
Get TfL data with tfl-ts
Pass normalised data to tfl-components
Render a useful interface
```

### Two layers in `tfl-components`

1. **Data-aware components** — accept normalised `tfl-ts` data and render useful transport UI.  
2. **Rendering primitives** — presentational building blocks from explicit values.

Shared brand language lives in **Foundations**. **Maps** split geographic vs schematic. **Explorer** explains what TfL knows (work in progress). **Blocks** compose several parts into mini-apps. **Tools** are playgrounds; **Drafts** incubate experiments.

### Distribution

```bash
pnpm dlx shadcn@latest add https://tfl.manglekuo.com/r/tube-status-board.json
```

Put `TFL_APP_KEY` (Primary key from the [TfL API portal](https://api-portal.tfl.gov.uk/)) in your server environment. See [Installation](/docs/installation).

Press `d` to toggle dark mode.
