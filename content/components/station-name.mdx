## Purpose

Reusable station / stop name renderer with deterministic TfL-aware line breaking and abbreviation. Used by line and branch strips; tunable in the Station typography tool.

## Preview

See above when a demo is available. Typical production use:

```tsx
import { StationName } from "@/components/tfl/station-name"

<StationName
  name="King's Cross St. Pancras"
  layout="auto"
  maxWidth={140}
  maxLines={2}
  allowAbbreviation
/>
```

## API / values

| Prop | Description |
|------|-------------|
| `name` | Raw station name |
| `layout` | `"fixed"` (explicit `lines`) or `"auto"` (measure + break) |
| `lines` | Editorial visual lines — skips auto break |
| `maxWidth` / `fontSize` | Measurement box |
| `maxLines` | `1` or `2` |
| `allowAbbreviation` / `allowScaleDown` | Fit strategies |

Two-line results use a unitless line-height so wrap and scale-down stay clustered and vertically centered in the parent. Prefer not to override with rem `leading-*` on multiline labels.

When paint wraps or abbreviates, the canonical name is exposed with `hidden="until-found"` so Cmd/Ctrl+F can match the full single-line form and reveal it under the label. This is composed from the shared `FindableText` primitive (`@/components/tfl/findable-text`) — reach for it directly if you're building a new component with the same abbreviated/`<br>`-split paint problem; see [`.cursor/rules/findable-identity-text.mdc`](../../.cursor/rules/findable-identity-text.mdc).

## Composition

Break rules live in `@/lib/tfl/station-typography` (`formatStationLabel`). The Tool exposes box width, font size, abbreviation, and scale controls that do **not** all belong on the production component API.

## Used by

Data-aware [Line strip](/interfaces/line-strip), [Branch strip](/primitives/branch-strip), and the [Week ahead](/blocks/week-ahead) Block. For the fit, abbreviation, and copy/find story see [Station labels](/foundations/station-labels). Tune behaviour in [Station typography](/tools/typography).

## Independence notes

No `tfl-ts` fetch. Works with any string name; TfL awareness is in break/abbreviation heuristics.
