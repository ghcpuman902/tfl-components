## Fit

Reusable station and stop name renderer. Deterministic TfL-aware line breaking and abbreviation. Tune behaviour in the [Station typography](/tools/typography) tool.

```tsx
import { StationName } from "@/components/tfl/station-name"

<StationName
  name="King's Cross St. Pancras"
  layout="auto"
  maxWidth={140}
  maxLines={2}
  allowAbbreviation
/>
```

| Prop | Description |
|------|-------------|
| `name` | Raw station name |
| `layout` | `"fixed"` (explicit `lines`) or `"auto"` (measure + break) |
| `lines` | Editorial visual lines. Skips auto break |
| `maxWidth` / `fontSize` | Measurement box |
| `maxLines` | `1` or `2` |
| `allowAbbreviation` / `allowScaleDown` | Fit strategies |

Two-line results use a unitless line-height so wrap and scale-down stay clustered and vertically centered. Prefer not to override with rem `leading-*` on multiline labels.

When paint wraps or abbreviates, the canonical name is exposed with `hidden="until-found"` so find-in-page can match the full name. That comes from `FindableText`. Reach for it if you are building a new abbreviated label.

Break rules live in `@/lib/tfl/station-typography` (`formatStationLabel`). No `tfl-ts` fetch. Works with any string name.

For the fit, abbreviation, and copy/find story see [Station name labels](/docs/station-name-labels).
