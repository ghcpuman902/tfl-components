## Usage

```tsx
import { HorizontalLineDiagram } from "@/components/tfl/diagram/horizontal-line-diagram"
import { JourneyDiagram } from "@/components/tfl/diagram/journey-diagram"
import { LineRouteDiagram } from "@/components/tfl/diagram/line-route-diagram"

// stations: DiagramStation[] from toDiagramStation / curated data
```

### Components

| Component | Role |
|-----------|------|
| `HorizontalLineDiagram` | Compact strip with interchange flags (§10). Optional `fit` mode (no horizontal scroll) and `segments` for §5.1 out-of-use stretches |
| `LineRouteDiagram` | Full vertical route with station names (§11) |
| `JourneyDiagram` | A→B journey with expandable intermediates |

```tsx
<HorizontalLineDiagram
  lineColor="#039BE5"
  stations={stations}
  fit
  segments={[
    { fromStationId: "a", toStationId: "b", state: "out-of-use" },
  ]}
  forceLabelIds={["a", "b"]}
/>
```

Map TfL stop points with `toDiagramStation` and slice a trip with `sliceJourney` from `@/lib/tfl/diagram-mappers`.

### Standards

Geometry ratios live in `@/lib/tfl/line-diagram` (`LINE_DIAGRAM`, scale CSS vars). They follow *Line diagram standard* Issue 4. Reference crops are in `public/brand/line-diagram/`.

### Brand notes

- Official line colours are fine.
- Do not redistribute Johnston without a licence — this demo uses Hammersmith One as a stand-in.
- §9 connection flags: Underground first (α), then other TfL modes, then National Rail. TOC names such as Greater Anglia / c2c collapse to **National Rail** by default (`nationalRailFlags: "collapse"` on `toDiagramStation`); pass `"operators"` to keep TOC labels.
- Closed / out-of-use stretches render as a full-thickness muted solid (not dashed).
- Fitted mode is left-aligned with a fixed station pitch; pass `sharedFitScale` when several diagrams must match.
