## Purpose

Molecular horizontal line strip for TfL-style schematic corridors — explicit station values, colour, closures, and label recipes. Primary docs home for this primitive; schematic discovery also lives under [Maps → Schematic](/maps/schematic).

## Installation

```bash
pnpm dlx shadcn@latest add https://tfl-components.vercel.app/r/line-strip.json
```

## Preview

See the interactive preview above. Pass prepared stations and optional segments — no TfL fetch inside the primitive.

## API / values

```tsx
import { LineStrip } from "@/components/tfl/diagram/line-strip"
import { StraightStrip } from "@/components/tfl/diagram/straight-strip"
import { BranchStrip } from "@/components/tfl/diagram/branch-strip"
import { JourneyDiagram } from "@/components/tfl/diagram/journey-diagram"
import { LineRouteDiagram } from "@/components/tfl/diagram/line-route-diagram"

// Prefer LineStrip for TfL line data — it prepares labels, closures, and colour.
```

### When to use which

| Need | Use |
|------|-----|
| TfL line data, label recipes, closures, colour | `LineStrip` (molecular) |
| Linear corridor with already-prepared stations | `StraightStrip` (atomic) |
| Branched schematic with prepared nodes / labels | `BranchStrip` (atomic) |

Start with `LineStrip`. Drop to atoms only when you need full control over the render model. See also [Branch strip](/primitives/branch-strip).

### Layers

| Component | Layer | Role |
|-----------|-------|------|
| `StraightStrip` | Atomic | Linear strip — render prepared stations / segment states only |
| `BranchStrip` | Atomic | Branched lane×pos schematic — render prepared nodes / labels only |
| `LineStrip` | Molecular | TfL-aware: colour, adjacency, closures, label recipes → atom |
| `LineRouteDiagram` | Vertical map | Full vertical route with station names |
| `JourneyDiagram` | Journey | A→B journey with expandable intermediates |

```tsx
<LineStrip
  lineId="victoria"
  lineColor="#039BE5"
  labelPlacement="alternate"
  stations={stations}
  fit
  segments={[
    { fromStationId: "a", toStationId: "b", state: "out-of-use" },
  ]}
  stationOutOfUseIds={["interior-stop"]}
  forceLabelIds={["a", "b"]}
/>
```

For branched lines, pass a schematic:

```tsx
<LineStrip
  lineId="northern"
  schematic={NORTHERN_LINE_SCHEMATIC_HORIZONTAL}
  lineColor={getLineColor("northern").hex}
/>
```

Map TfL stop points with `toDiagramStation` and slice a trip with `sliceJourney` from `@/lib/tfl/diagram-mappers`. Preparation helpers live in `@/lib/tfl/strip-model`.

### Part closures

For “no service between A and B”, mute the **track** with `segments`. `LineStrip` derives station greys with the all-adjacent-closed rule: a stop stays coloured if it still has an open side (e.g. Queen’s Park), and greys when every adjacent segment is closed. Full-route closures grey every station. When `stationOutOfUseIds` is omitted, it is derived from `segments`.

### Label placement

`labelPlacement`: `"above"` (default) | `"below"` | `"alternate"`. Alternate reserves both name bands so markers stay aligned across the strip. Editorial two-line recipes are applied by `LineStrip`, not by the atoms.

## Composition

Geometry ratios live in `@/lib/tfl/line-diagram` (`LINE_DIAGRAM`, scale CSS vars). They follow *Line diagram standard* Issue 4. Reference crops are in `public/brand/line-diagram/`.

## Independence notes

`LineStrip` accepts explicit values (stations, colour, schematic). It does not call `tfl-ts` for network status. Helpers may use TfL colour IDs from Foundations / `tfl-ts` colour utilities.

## Brand notes

- Official line colours are fine.
- Do not redistribute Johnston without a licence — this demo uses Hammersmith One as a stand-in.
- §9 connection flags: Underground first (α), then other TfL modes. Bus / unknown line IDs are dropped.
- National Rail is **not** a text flag — set `nationalRail: true` on the station (or let `toDiagramStation` detect TOCs) to show the NR pictogram beside the name without shifting text centering.
- Closed / out-of-use stretches render as a full-thickness muted solid (not dashed).
- Fitted mode is left-aligned with a fixed station pitch; pass `sharedFitScale` when several strips must match.
