## Get a spine

Fetch a route sequence in your app, or use the site helper, prepare stations, then pass a spine:

```ts
import { getLineSpine } from "@/lib/tfl/line-spine"

const spine = await getLineSpine("victoria")
```

`getLineSpine` uses `tfl.line.getRouteSequence` under the hood. Fetching stays outside `LineStrip`. You can also pass explicit `stations` prepared with `toDiagramStation`.

## Render

```tsx
import { LineStrip } from "@/components/tfl/diagram/line-strip"

export default function Page({ spine }) {
  return <LineStrip lineId="victoria" spine={spine} fit />
}
```

Branched schematic:

```tsx
<LineStrip
  lineId="northern"
  schematic={NORTHERN_LINE_SCHEMATIC_HORIZONTAL}
  lineColor={getLineColor("northern").hex}
/>
```

`StraightStrip` and `BranchStrip` stay available when you already have a prepared visual model. Prefer `LineStrip` when you have TfL line data.

Pass `mono` for B&W Tube-map stroke motifs on the graph (dashed channels, double/triple rails). Mono is SVG, not a CSS role token — it belongs on strips, not titles or chips. Scale it with `x`.

## When to drop to primitives

| Need | Use |
|------|-----|
| TfL line data, label recipes, closures, colour | `LineStrip` |
| Linear corridor with already-prepared stations | `StraightStrip` via the line-strip package |
| Branched schematic with prepared nodes | [Branch strip](/docs/branch-strip) |
| Station label fitting only | [Station name labels](/docs/station-name-labels) |

## Part closures

For "no service between A and B", mute the track with `segments`. `LineStrip` greys stations when every adjacent segment is closed. Closed stretches render as a full-thickness muted solid.

Official line colours are fine. Do not redistribute Johnston without a licence. Demos use Hammersmith One. Prepare spine or schematic in the app or a Block. See [Week ahead](/blocks/week-ahead).
