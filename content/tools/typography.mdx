## Station typography

Tool for inspecting and tuning destination labels. Box width, font size, line-count, abbreviation, and scale controls belong here — they do not all need to become production component props.

### Related component

The reusable renderer is **[Station name](/primitives/station-name)** (`StationName`). Prefer that page for production usage.

### Production example from playground settings

```tsx
import { StationName } from "@/components/tfl/station-name"

<StationName
  name="King's Cross St. Pancras"
  layout="auto"
  maxWidth={140}
  maxLines={2}
  allowAbbreviation
  allowScaleDown
  minScale={0.75}
/>
```

Adjust `maxWidth`, `maxLines`, and abbreviation flags to match what you measured in this lab.

### Break rules (owned by StationName)

1. Prefer a single line when it fits.
2. Otherwise try every split **between words** and pick the most balanced pair that fits.
3. Optional abbreviations (`Street` → `St`, …) only when enabled.
4. Optional scale-down (floor **0.75**) as the last resort.

### Why a tool

This page exists to inspect / tune / debug label fitting. It is not an installable registry item and is not the production component API.
