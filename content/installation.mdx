## Installation

Copy a component into your Next.js app with the shadcn CLI. The registry item declares `tfl-ts` and any UI dependencies.

### Recommended

```bash
pnpm dlx shadcn@latest add https://tfl.manglekuo.com/r/tube-status-board.json
```

That one URL pulls the board plus its TfL deps (`line-badge`, `tfl-roundel`, colour tokens) as absolute registry URLs. Official shadcn atoms (`button`, `skeleton`, …) still resolve from the default registry.

See the [Components catalogue](/docs/components) for Arrivals, Line strip, Roundel, Colours, and other installable items.

### Optional: `@tfl` namespace

If you install several items, add the registry once in `components.json`:

```json
{
  "registries": {
    "@tfl": "https://tfl.manglekuo.com/r/{name}.json"
  }
}
```

Then:

```bash
pnpm dlx shadcn@latest add @tfl/tube-status-board
```

### API keys

Register at the [TfL API portal](https://api-portal.tfl.gov.uk/) and set:

```env
TFL_APP_ID=your-app-id
TFL_APP_KEY=your-app-key
```

Keys stay on the server. Do not place credentials inside reusable components.

### Example data vocabulary

| Source | Use |
|--------|-----|
| **Cached data** | Site / app cache for general demos |
| **Fixture data** | Deterministic states (severe delays, empty boards) |
| **Live data** | Developer credentials in the application layer |
